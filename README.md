# Automated Otitis Media Diagnosis from Otoscopic Images Using Deep CNNs

## 📌 Project Overview

This project presents an **AI-based system for automated diagnosis of Otitis Media and related ear conditions using otoscopic images**.

A **Deep Convolutional Neural Network (CNN)** is used to learn visual features from otoscopic images and classify them into different categories. The system demonstrates the application of **deep learning, image processing, and machine learning in healthcare**.

> **Note:** This project is intended for academic and research purposes and should not be used as a replacement for professional medical diagnosis.

---

## 🎯 Objectives

* Develop an automated system for otoscopic image classification.
* Use Deep CNNs to identify different ear conditions.
* Reduce the effort required for manual image classification.
* Apply computer vision and deep learning techniques to healthcare.
* Provide a simple system for testing otoscopic images.

---

## 🩺 Disease / Condition Classes

The system classifies otoscopic images into **five categories**:

* **Acute Otitis Media**
* **Cerumen Impaction**
* **Chronic Otitis Media**
* **Myringosclerosis**
* **Normal**

---

## 🧠 Methodology

The general workflow of the project is:

```text
Otoscopic Image
       ↓
Image Preprocessing
       ↓
Deep CNN
       ↓
Feature Extraction
       ↓
Image Classification
       ↓
Predicted Ear Condition
```

The CNN automatically learns important visual patterns from the images and uses these learned features to classify new otoscopic images.
